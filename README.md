# Тестове завдання: Основна механіка гри для Unity Developer  
Для виконання цього завдання я витратив 16-18 годин
## Опис  
Мета завдання — створити основну механіку гри, в якій гравець керує туреллю, встановленою на автомобілі, що рухається вперед. Завдання гравця — вижити на рівні, знешкоджуючи ворогів, при цьому зберігаючи ХП автомобіля.  

### Основна механіка  
1. **Турель під керуванням гравця:**  
   - Гравець регулює напрямок стрільби турелі для знищення ворогів.  
2. **Автомобіль, що рухається:**  
   - Рух автомобіля починається після натискання на екран.  
   - Камера переходить до вигляду ззаду автомобіля.  
3. **Вороги:**  
   - Вороги у стані очікування розміщені у випадкових місцях попереду.  
   - При наближенні автомобіля вороги починають переслідувати його та завдавати шкоди.  
4. **Кінцеві умови гри:**  
   - **Перемога:** Гравець проходить рівень до кінця.  
   - **Програш:** ХП автомобіля падає до нуля.
